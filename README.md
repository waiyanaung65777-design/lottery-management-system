# 🎯 2D 3D Lottery Management System (ဒိုင် & ကော်မရှင် စာရင်းကိုင်စနစ်)

မြန်မာ့ 2D / 3D လောကတွင် လက်တွေ့အသုံးများသော စနစ်ပုံစံအတိုင်း ရေးဆွဲထားသည့် Full-Stack Web Application ဖြစ်ပါသည်။

---

## 🌟 အဓိက ပါဝင်သော လုပ်ဆောင်ချက်များ (Core Features)

1. **⚡ Smart Bet Parser (အလိုအလျောက် ဂဏန်းဖြန့်စနစ်):**
   - ထိုးသားများ Telegram မှ ပို့သော စာသားများကို ကော်မရှင် (Agent) က Copy-Paste သို့မဟုတ် အမြန်ရိုက်ထည့်ရုံဖြင့် စနစ်က အလိုအလျောက် ခွဲထုတ်ပေးခြင်း။
   - **2D (R / အာ):** `45 R 200` သို့မဟုတ် `45 အာ 200` ရိုက်ပါက `45: 200` နှင့် `54: 200` (စုစုပေါင်း ၄၀၀ ကျပ်) အဖြစ် အော်တို ခွဲပေးခြင်း။
   - **3D (R / ပတ်လည်):** `123 R 500` ရိုက်ပါက ဖြစ်နိုင်ခြေ ၆ ကွက် (`123, 132, 213, 231, 312, 321`) တစ်ကွက်လျှင် ၅၀၀ ကျပ်စီ အလိုအလျောက် ဖြန့်ပေးခြင်း။
   - **မြန်မာဂဏန်း Support:** `၄၅ အာ ၂၀၀` ဟု ရိုက်လျှင်လည်း အလိုအလျောက် နားလည်ခြင်း။
   - **Shorthand ဖြတ်လမ်းများ:**
     - `ပူး 200` / `အပူး 200` (အပူး ၁၀ ကွက်)
     - `4ထိပ် 300` (၄၀ မှ ၄၉ အထိ ၁၀ ကွက်)
     - `5ပိတ် 300` (၀၅ မှ ၉၅ အထိ ၁၀ ကွက်)
     - `ပါဝါ 100` / `နက္ခတ် 100` / `ညီကို 100`

2. **👤 ကော်မရှင် (Agent Portal):**
   - **Live Preview:** စာရိုက်နေစဉ်တွင်ပင် စုစုပေါင်းထိုးငွေ၊ မိမိရရှိမည့် ကော်မရှင် (ဥပမာ ၁၅%)၊ ဒိုင်ဆီသို့ သွင်းရမည့်ငွေတို့ကို ချက်ချင်း တွက်ပြခြင်း။
   - **Telegram Receipt Generator:** ဒိုင်ဆီ စာရင်းတင်ပြီးပါက ထိုးသားထံ Telegram သို့ ပြန်ပို့နိုင်သော သပ်ရပ်သည့် စလစ်စာသားကို 1-Click Copy ကူးယူနိုင်ခြင်း။
   - **My Slips & Ledger:** မိမိတင်ထားသော စလစ်များ၊ ပေါက်/မပေါက် အခြေအနေနှင့် ရရှိပြီး ကော်မရှင် ရှင်းတမ်းများ ကြည့်ရှုနိုင်ခြင်း။

3. **👑 ဒိုင်ချုပ် (Banker Dashboard):**
   - **Risk Heatmap:** မည်သည့်ဂဏန်းတွင် ငွေပမာဏ မည်မျှအထိ ထိုးထားသည်ကို အချိန်နှင့်တပြေးညီ ကြည့်ရှုနိုင်ခြင်း (ဒိုင် အန္တရာယ် စစ်ဆေးချက်)။
   - **ဘရိတ် / ပိတ်ဂဏန်း သတ်မှတ်ခြင်း (Hot Limits):** ဂဏန်းတစ်ခုချင်းအလိုက် အများဆုံး လက်ခံမည့် Limit သတ်မှတ်နိုင်ခြင်း သို့မဟုတ် လုံးဝ ပိတ်ဂဏန်း (Block) ထားရှိနိုင်ခြင်း။
   - **ပေါက်ဂဏန်း သွင်းခြင်းနှင့် အော်တို ငွေရှင်းခြင်း (Settle):** ပေါက်ဂဏန်း ရိုက်ထည့်လိုက်ရုံဖြင့် စလစ်အားလုံးကို စနစ်က စက္ကန့်ပိုင်းအတွင်း အော်တိုစစ်ဆေးပြီး အနိုင်ရသူများအား ပေါက်ငွေတွက်ပေးခြင်း။
   - **Financial Ledger:** စုစုပေါင်း အထိုးငွေ၊ ကော်မရှင်ပေးရငွေ၊ ဒိုင်ရောင်းရငွေ၊ ပေါက်ငွေအလျော်နှင့် ဒိုင်အသားတင် အမြတ်/အရှုံး စာရင်းချုပ်။

---

## 🚀 စနစ် စတင်အသုံးပြုပုံ (How to Run)

1. Server စတင်ဖွင့်ရန်:
   ```bash
   node server.js
   ```
2. Browser တွင် အောက်ပါ Link သို့ ဝင်ရောက်အသုံးပြုနိုင်ပါသည်:
   ```
   http://localhost:3000
   ```

3. အပေါ်ဘက် ညာဘက်ထောင့်ရှိ **"လက်ရှိသုံးနေသူ"** Dropdown တွင်:
   - `ဒိုင်ချုပ်ကြီး (Master)` ရွေးချယ်ပါက ဒိုင်ချုပ် စီမံခန့်ခွဲရေး Dashboard သို့ ရောက်ရှိမည်။
   - `ကိုအောင် (Agent 1)` သို့မဟုတ် `ကိုကျော် (Agent 2)` ရွေးချယ်ပါက ကော်မရှင် စာရင်းတင်သွင်းရေး မျက်နှာပြင်သို့ ရောက်ရှိမည် ဖြစ်ပါသည်။
